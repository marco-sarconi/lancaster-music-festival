Lancaster Music Festival 2026 Planner - standalone app

Put all the files in this folder on any static web host (HTTPS required for install and offline):
  - Netlify: app.netlify.com/drop - drag this folder onto the page
  - GitHub Pages: push the folder to a repo, then Settings > Pages > deploy from branch
  - Cloudflare Pages: Create project > Direct upload > choose this folder

Then open the site on your phone in Safari, tap Share > Add to Home Screen.
Picks are saved on the phone, and the app works offline once it has opened with signal.

To update listings: replace index.html with a new build. The app picks it up next time it opens with signal.
